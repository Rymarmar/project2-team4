# Reactive Banking

Reactive Banking is the premier React and TypeScript banking frontend with an account dashboard, transaction forms, and transaction history. It uses Bootstrap for responsive layout, and solid white cards for readability.

## Features

- Login and registration forms with field validation
- Protected pages and session restoration
- Dashboard with checking and savings balances and recent transactions
- Deposit, withdrawal, and transfer forms
- Paginated transaction history with transaction type colors
- Toast notifications and loading and error states

## Technology

React 19, TypeScript, Vite, React Router, Bootstrap, React Bootstrap, and ESLint.

## Getting started

Install Node.js 22.12 or later and npm. From the repository root:

```bash
cd frontend
npm ci
npm run dev
```

Open the local URL printed by Vite.

## Commands

Run these commands from `frontend/`:

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Check TypeScript and create a production build in `dist/` |
| `npm run preview` | Serve the production build locally |
| `npm run lint` | Run ESLint |
